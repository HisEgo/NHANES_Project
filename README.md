# بررسی رابطه شاخص توده بدنی و فشار خون سیستولیک با استفاده از داده‌های NHANES

## معرفی پروژه

این پروژه با هدف بررسی رابطه آماری بین شاخص توده بدنی (BMI) و فشار خون سیستولیک در بزرگسالان ۲۰ سال به بالا انجام می‌شود.

داده‌های مورد استفاده از پیمایش ملی سلامت و تغذیه ایالات متحده (NHANES)، مربوط به دوره آگوست ۲۰۲۱ تا آگوست ۲۰۲۳، دریافت شده‌اند.

این پژوهش از نوع مشاهده‌ای و مقطعی است؛ بنابراین نتایج آن برای بررسی ارتباط آماری متغیرها به کار می‌روند و نباید به‌عنوان شواهدی از رابطه علت و معلولی تفسیر شوند.

## پرسش اصلی پژوهش

آیا بین شاخص توده بدنی (BMI) و فشار خون سیستولیک در بزرگسالان ۲۰ سال به بالا، ارتباط آماری وجود دارد؟

سن و جنس نیز به‌عنوان متغیرهای تکمیلی برای بررسی و مقایسه‌های توصیفی در نظر گرفته شده‌اند.

## منبع داده‌ها

داده‌ها از وب‌سایت رسمی مرکز ملی آمار سلامت ایالات متحده (NCHS) و مجموعه‌داده NHANES دریافت شده‌اند.

فایل‌های مورد استفاده:

| فایل | محتوای اصلی |
|---|---|
| `DEMO_L.xpt` | اطلاعات جمعیت‌شناختی، سن، جنس و متغیرهای طراحی نمونه‌گیری |
| `BMX_L.xpt` | اندازه‌گیری‌های بدنی، از جمله BMI |
| `BPXO_L.xpt` | اندازه‌گیری‌های فشار خون |

شناسه `SEQN` برای اتصال فایل‌ها به یکدیگر استفاده شده است.

توضیحات کامل درباره منبع داده‌ها، فایل‌های مورد استفاده و روش بازسازی مجموعه‌داده در فایل [`data/README.md`](data/README.md) آمده است.

## روش اجرای پروژه

### ۱. نصب وابستگی‌ها

ابتدا محیط پایتون را فعال کنید و وابستگی‌های پروژه را نصب کنید:

```bash
pip install -r requirements.txt
```

### ۲. دریافت داده‌ها

فایل‌های خام مورد نیاز را مطابق راهنمای موجود در `data/README.md` دریافت کرده و در پوشه `data/raw/` قرار دهید.

### ۳. اجرای کد

فایل زیر را در محیط Jupyter باز و سلول‌های آن را به‌ترتیب اجرا کنید:

```text
notebooks/phase1_exploration.ipynb
```

## محدودیت‌ها

- برخی مشاهدات دارای داده‌های گمشده هستند.
- داده‌ها حاصل یک پیمایش مقطعی هستند و امکان نتیجه‌گیری علّی را فراهم نمی‌کنند.
- طراحی نمونه‌گیری NHANES پیچیده است و در تحلیل‌های استنباطی باید وزن‌ها، طبقات و خوشه‌های نمونه‌گیری در نظر گرفته شوند.

## مجوز و منبع داده

داده‌ها متعلق به NHANES و مرکز ملی آمار سلامت ایالات متحده (NCHS) هستند. برای اطلاعات بیشتر به [وب‌سایت رسمی NHANES](https://www.cdc.gov/nchs/nhanes/) مراجعه کنید.
